## 三、编译与使用

### 编译成 PDF

```bash
cd 01_项目计划书
xelatex 项目计划书_带图版.tex
xelatex 项目计划书_带图版.tex      # 必须两次：第一次生成目录与交叉引用
```

- **必须用 XeLaTeX**（含中文，pdfLaTeX 会报错）
- 也可把 `01_项目计划书/` 整个上传 [Overleaf](https://www.overleaf.com)，编译器选 XeLaTeX
- 中文字体使用"微软雅黑"（Windows 自带）；换到 mac/Linux 时需在 `04_生成脚本/assemble_tex.py` 里改字体名后重新生成

### 换成自己的图片

在 `项目计划书.tex` 中把占位

```latex
\fbox{\parbox[c][4.5cm][c]{0.8\textwidth}{\centering 【图片空位：imageN.ext】…}}
```

换成 `\includegraphics[width=0.8\textwidth]{项目计划书图片/imageN.ext}`（表格内用 `width=2.4cm`）。占位框里标注了对应文件名。

### 改内容后重新生成

改 `03_LaTeX片段/` 里的片段 → 把 `04_生成脚本/` 里的脚本放回项目根目录运行：

```bash
python assemble_tex.py        # 拼装成完整 .tex
python make_with_images.py    # 生成"带图版"
python make_cover.py          # 重新生成封面（改封面文字/图片时用）
python check_final.py         # 完整性校验
```

（脚本中的路径基于项目根目录 `BIT_CD/`，故需放回原处运行。）

## 四、需要留意的数据口径

写进文档的数字已做过口径核实，答辩时若被追问可据此回答：

| 数据 | 口径说明 |
|---|---|
| 识别精确率 **70%** | 黑土地**试点场景**下的业务指标，与模型在公开基准数据集上实测的 mF1（0.8868）**不是同一指标**，不可直接比较（附录 B 表注已说明） |
| 算力成本降低 **69%** / 监测周期缩短 **33%** | 33% 指**单次监测任务周期**（不含影像重访等待），成果更新**频次**为周级（附录 B 已分开表述） |
| 黑土层减薄 **6.83cm** / 年均流失 **0.5–1cm** | 前者是区域**累计值**，后者是**年速率**，二者为同一现象的不同计量口径（正文已相互印证说明） |
| 数据集类别有两套 | "土地变化/海上建设/城市建筑/森林变化"为**通用变化判别**训练样本；"侵蚀沟发育/水土流失/土壤有机质流失/耕地违规破坏"为黑土地**场景适配**目标类别，构成"通用预训练 + 场景适配"两级策略（第八章已说明） |
| GF-2 分辨率 | **星下点**实际成像 0.8m/3.2m；相机**标称**为 1m/4m，两种口径并存（附录 A 表注已说明） |

**已删除的数据**：原文中"单张影像推理 0.7 秒""日均处理 10 万张"——前者与项目测试记录（实测 3–5 秒/张）矛盾，后者按此耗时算需 97 小时/日，物理上不可能，故全书删除。

**软件著作权**：文档写"3 项"，实际只提供了 2 张证书图（image27、image28），第 3 项无图 —— 如评委要求出示，需另行准备。
