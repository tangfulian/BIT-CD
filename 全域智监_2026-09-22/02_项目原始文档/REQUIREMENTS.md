# BIT_CD 黑土地遥感变化检测系统 —— 需求文档

> 版本: v1.1 | 日期: 2026-05-29 | 作者: BIT_CD 开发团队

---

## 1. 项目背景

东北黑土地是我国重要的粮食生产基地，但长期面临水土流失、耕地沙化、非农化、非粮化等问题。传统人工巡查效率低、成本高，遥感变化检测技术可实现大范围、高频次的自动化监测。

BIT_CD (BlackLand Change Detection) 是一套面向黑土地保护的遥感变化检测智能平台，融合深度学习变化检测模型、AI 智能分析与 GIS 地图技术，为农业管理部门和科研机构提供从影像上传、变化检测、结果分析到报告生成的全流程一站式服务。

| 角色 | 权限说明 |
|------|---------|

## 3. 功能需求

### 3.1 用户认证模块 (FR-AUTH)

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-AUTH-01 | 用户注册：用户名 + 密码 + 验证码，自动分配 user 角色 | P0 |
| FR-AUTH-02 | 用户登录：用户名 + 密码，返回 JWT 令牌，24 小时有效 | P0 |
| FR-AUTH-03 | 验证码：服务端生成 4 位数字图片验证码，支持点击刷新 | P1 |
| FR-AUTH-04 | 修改密码：验证旧密码后更新 | P1 |
| FR-AUTH-05 | 用户管理（管理员）：列表查看、启用/禁用、重置密码、删除用户及关联数据 | P1 |
| FR-AUTH-06 | 接口限流：全接口覆盖（登录 5/分、注册 3/分、检测 10/分、Agent 3/分、标注 20/分、地块 20/分 等），防暴力破解与资源滥用 | P1 |
| FR-AUTH-07 | JWT 鉴权：所有业务接口需携带有效 Token | P0 |

### 3.2 变化检测模块 (FR-DETECT)

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-DETECT-01 | 单张检测：上传 T1/T2 影像对，选择模型与阈值，返回变化二值掩膜、热力图、融合叠加图 | P0 |
| FR-DETECT-02 | 批量检测：多组影像对顺序检测，显示进度，支持暂停/恢复/导出 CSR/PDF 报告 | P1 |
| FR-DETECT-03 | MD5 缓存：相同影像+模型+阈值命中缓存，即时返回结果 | P1 |
| FR-DETECT-04 | 交互调阈值：检测完成后拖动滑块实时调整，无需重新推理 | P1 |
| FR-DETECT-05 | Otsu 自动阈值：基于分数图自动计算最优二值化阈值 | P2 |
| FR-DETECT-06 | 多模型对比：同一影像对同时运行多个模型，横向比较结果 | P2 |
| FR-DETECT-07 | NDVI 分析：计算归一化植被指数并分级（水体/裸土/低/中/高植被） | P2 |
| FR-DETECT-08 | 面积统计：变化区域面积换算（像素/m²/亩/公顷） | P1 |
| FR-DETECT-09 | GeoJSON 导出：二值掩膜转为多边形 GeoJSON | P2 |
| FR-DETECT-10 | 图像预处理：客户端旋转、翻转、裁剪 | P2 |

### 3.3 AI 智能分析模块 (FR-AI)

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-AI-01 | AI 对话：通用问答助手，限定黑土地保护与遥感领域知识 | P1 |
| FR-AI-02 | 检测结果分析：生成结构化专家报告（概况/成因分析/治理建议），400-600 字 | P1 |
| FR-AI-03 | 变化类型分类：自动识别 6 类变化（水土流失/沙化/弃耕/非农化/非粮化/黑土层退化） | P1 |
| FR-AI-04 | AI Agent 浏览器操控：自然语言指令驱动浏览器自动完成任务（导航/登录/检测/查看历史） | P2 |

### 3.4 历史记录模块 (FR-HISTORY)

| 编号 | 需求 | 优先级 |
|------|------|--------|

| FR-HISTORY-02 | 详情弹窗：展示全部结果图（T1/T2/掩膜/热力图/融合）+ AI 分类信息 | P1 |
| FR-HISTORY-03 | 单条删除 + 清空全部 | P1 |
| FR-HISTORY-04 | 对比模式：选两条记录并排对比，计算差异 | P2 |

## 4. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| NFR-01 | 性能 | 单张检测响应 < 10s（含模型推理），批量并发 3 任务 |
| NFR-02 | 安全 | 密码 bcrypt 哈希；JWT HS256 签名；接口限流；CORS 白名单 |
| NFR-03 | 可用性 | 界面中文优先，英文备选；错误提示友好 |
| NFR-04 | 兼容性 | 支持 Chrome/Edge/Firefox 最新版本；File System Access API 需 HTTPS 或 localhost |
| NFR-05 | 部署 | Docker 容器化 + 本地 Python 直接启动双模式；生产环境阿里云 ECS |
| NFR-06 | 数据 | SQLite（开发/单机/生产统一使用），通过 SQLAlchemy ORM 隔离 |

## 5. 支持的变化检测模型

| 模型 | 架构 | 说明 |
|------|------|------|
| BIT | ResNet18 + Transformer | 位时相影像 Transformer，推荐默认模型 |
| DIFF | 像素差值 | 传统方法基准 |
| FC_SIAM_DIFF | 全卷积孪生网络 | 共享编码器 + 特征差分 |
| SNUNET | 嵌套 UNet | 多尺度 + 深度监督 |
| CHANGEFORMER | ResNet + Transformer | 最深特征做 Transformer 瓶颈 |
| AFCF3D | 3D 卷积 | 自适应特征分解 + 3D 融合 |
| BIT_LuojiaSET | BIT 架构 | 珞珈 SET 数据集微调版本 |
