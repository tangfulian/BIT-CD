# BIT_CD 比赛演示脚本

> 适用场景：科创比赛系统演示 | 建议分辨率：1920×1080

---

## 录制前准备

1. **提前登录**：打开浏览器访问系统，提前登录好账号（避免在视频中浪费时间输入密码）
2. **准备样本数据**：在 `samples/` 目录下准备好 2-3 组 T1/T2 遥感影像对（建议选变化明显的图，演示效果更好）
3. **清理环境**：关闭无关标签页、通知弹窗，桌面整洁
4. **浏览器设置**：F12 开发者工具关闭，书签栏隐藏，使用干净浏览器窗口
5. **网络检查**：确保服务器可访问，DashScope API Key 有效（AI 分析功能需要）
6. **录屏工具**：推荐 OBS Studio，录制区域选浏览器窗口，帧率 30fps，音频开启

## 一、10 秒演示（快速展示核心能力）

### 演示目标
用最短时间展示"上传两张遥感影像 → AI 自动检测变化区域"的核心功能，给评委留下第一印象。

### 操作步骤（全程约 10 秒）

| 时间 | 操作 | 画面 |
|------|------|------|
| 0-2s | 已提前进入单张检测页面 | 页面标题"单张影像检测"，界面已就绪 |
| 2-4s | 点击"T1影像"上传按钮 → 选择图片 | 左侧预览区出现 T1 影像 |
| 4-6s | 点击"T2影像"上传按钮 → 选择图片 | 右侧预览区出现 T2 影像 |
| 6-8s | 点击"开始检测"按钮 | 进度条闪过（预缓存命中则更快） |
| 8-10s | 结果展示 | 四宫格（T1 / T2 / 变化掩膜 / 热力融合图）同时呈现，画面定格 |

### 配音文本（语速快、节奏紧凑）

> 各位评委好，这是 BIT_CD 黑土地遥感变化检测系统。上传两期影像，点击检测，AI 自动识别耕地变化区域。谢谢！

#### 开场（0:00-0:25）
> 各位评委老师好，我演示的是 BIT_CD 黑土地遥感变化检测系统。这是一套面向东北黑土地保护的智能监测平台，融合了深度学习和遥感技术。登录后进入数据大屏，可以看到检测总量、变化面积等核心指标一览无余。

#### 核心检测（0:25-1:20）
> 系统的核心功能是变化检测。我们选择 BIT 模型——一种基于 Transformer 的双时相变化检测网络。上传 T1 和 T2 两期遥感影像，点击开始检测。系统在后台运行深度学习推理，大约 3 到 5 秒即可完成。结果以四宫格展示：左上 T1 原始影像，右上 T2 原始影像，左下二值变化掩膜，白色区域即为检测到的变化，右下是热力图与原始影像的融合叠加，直观呈现变化的空间分布。

#### AI 分析（1:20-2:00）
> 检测完成后，我们可以拖动阈值滑块实时调整灵敏度——掩膜范围会同步变化，无需重新推理。更重要的，我们接入了大语言模型进行智能解读：点击 AI 分析，系统自动生成一份结构化报告，涵盖变化概况、成因分析和治理建议。AI 分类功能可以自动识别六种变化类型，比如非农化、非粮化、水土流失等，并给出置信度。

#### 收尾（2:00-3:00）
> 所有检测记录保存在历史中，支持分页浏览和详情查看。系统还支持深色模式等细节体验。以上是 BIT_CD 系统的核心功能演示。谢谢各位评委！

### 配音文本

#### 开场：系统背景（0:00-0:30）
> 各位评委老师好！我带来的作品是 BIT_CD 黑土地遥感变化检测智能平台。东北黑土地是我国重要的粮食生产基地，但长期面临水土流失、非农化、非粮化等问题。传统人工巡查效率低、成本高，我们的系统利用深度学习技术实现大范围、高频次的自动化变化监测。这是系统登录后的数据大屏，可以直观看到检测总量、变化面积、变化类型分布和七日趋势。

#### 核心功能：AI 变化检测（0:30-1:45）
> 系统的核心是单张变化检测。我们集成了七种变化检测模型，包括经典的 BIT 双时相 Transformer、SNUNET 嵌套 UNet、CHANGEFORMER 等。默认推荐 BIT 模型。用户只需上传两期遥感影像——比如 T1 是 2023 年的耕地，T2 是 2024 年同一地块——点击检测，系统会自动运行深度学习推理，输出四种结果：变化二值掩膜、分数热力图、融合叠加图和面积统计。检测完成后，用户可以通过拖动阈值滑块实时调整检测灵敏度，掩膜范围会同步变化，无需重新推理，这在实际业务中非常实用。

> 更有价值的是，我们接入了大语言模型进行智能分析。点击"AI 分析"，系统会自动生成一份四百到六百字的结构化专家报告，包含变化概况、成因分析和针对性治理建议。AI 变化分类功能可以自动将变化识别为六大类型之一：水土流失、沙化、弃耕、非农化、非粮化或黑土层退化，并给出置信度，辅助管理人员快速判断。

#### 多模型对比与 NDVI（1:45-2:35）
> 不同模型对同一场景的检测结果可能存在差异。为此我们设计了多模型对比功能。以这组影像为例，我们同时运行 BIT、SNUNET 和 CHANGEFORMER 三个模型，可以看到它们对变化边界的刻画各有侧重——BIT 更关注全局语义，SNUNET 细节更丰富，CHANGEFORMER 对线性变化更敏感。多模型交叉验证可以提高检测结果的可信度。另外，我们还提供了 NDVI 植被指数分析，通过近红外和红光波段计算归一化植被指数，直观反映植被覆盖状况的变化。

#### 批量检测（2:35-3:15）
> 面对大规模监测需求，批量检测功能支持一次上传多组影像对顺序检测，实时显示进度条，支持暂停和恢复。检测完成后可以一键导出 CSV 统计报告，方便接入现有的数据管理流程。

#### 地块管理 + GIS（3:15-3:55）
> 在地块管理模块中，我们集成了高德地图，用户可以直接在地图上圈定关注的地块范围，录入省、市、面积、作物类型、土壤类型等信息，建立地块档案。系统支持 GPS 定位和逆地理编码，自动获取当前位置的行政区划信息。每个地块可以关联多次检测记录，形成时序变化追踪。

#### AI Agent 浏览器操控（3:55-5:00）
> 最后一个亮点是 AI Agent 浏览器操控功能。这是一个创新性的交互方式——用户只需用自然语言描述需求，比如"帮我查看最近三次检测历史"，Agent 会自动启动浏览器、导航到系统页面、执行操作并截图返回。这背后是视觉大模型驱动，通过 Chrome DevTools Protocol 控制浏览器。Agent 还可以完成更复杂的任务，比如自动登录、批量查询等。这个功能探索了遥感监测系统与大模型 Agent 结合的更多可能性。

> 以上是 BIT_CD 系统的完整演示。系统从底层深度学习模型到上层 Web 交互全部自主研发，已在阿里云服务器上稳定运行。感谢各位评委老师！

## 注意事项

1. **10 秒视频建议**：提前打开检测页面并完成登录，甚至提前加载好 T1/T2 图片，只留"点击检测按钮→展示结果"两个动作
2. **模型选择**：优先用 BIT 模型（默认推荐，名称专业）；如果已有缓存结果则秒出，效果更好
3. **样本影像**：选变化明显的影像对（如耕地变建筑、植被明显退化），视觉冲击力强
4. **语速控制**：3 分钟约 500-600 字配音，5 分钟约 900-1000 字配音，以上脚本已按此计算
5. **备用方案**：如果 AI 分析/AI Agent 接口不稳定，可提前录制好结果图作为备用
