BlackLand CD 黑土地遥感变化检测系统

v1.0.0

黑土地遥感变化检测智能平台，融合深度学习与GIS技术，为东北黑土地保护提供高效、精准的变化检测与数据分析解决方案。

技术栈

前端Vanilla JS + ECharts + 高德地图
后端Python FastAPI + SQLAlchemy
AI模型PyTorch BIT Transformer
数据库SQLite
AI服务DeepSeek（deepseek-v4-flash）

系统功能

·双时相遥感影像变化检测
·批量多模型对比分析
·AI智能解读与分类
·地块管理与时序追踪
·GIS地图可视化
·检测报告自动生成
