## 报告内容

按时间线完整记录项目开发全流程，含 9 章 + 5 个附录：

| 章 | 内容 |
|---|---|
| 1 | 项目概述（背景、目标、功能概览、技术架构） |
| 2 | 开发全流程时间线（7 个里程碑 + 8 个版本演进） |
| 3 | 阶段一 · 方案设计与需求分析 |
| 4 | 阶段二 · 模型实验与训练（BIT / SYSU-CD，实测 mF1 0.8868） |
| 5 | 阶段三 · 系统开发与版本迭代 |
| 6 | 阶段四 · 测试与问题排查（54 项用例，98.1% 通过） |
| 7 | 阶段五 · 安全加固与生产部署（13 项高危/中危修复） |
| 8 | 团队分工与协作 |
| 9 | 总结与展望 |
| 附录 A–E | 实验数据、GF-2 传感器参数、界面截图、检测结果、佐证材料清单 |

**特点**：全部数据取自项目真实记录 —— Git 提交历史、训练日志 `checkpoints/test/log.txt`、测试报告、系统实际截图，可逐项核验。

