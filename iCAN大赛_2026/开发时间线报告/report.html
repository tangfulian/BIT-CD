1项目概述

1.1 项目背景

东北黑土地是我国重要的粮食生产基地，但长期面临水土流失、耕地沙化、非农化、非粮化等问题。 传统人工巡查方式效率低、成本高，难以支撑大范围、高频次的耕地保护监测需求。 遥感变化检测技术（Remote Sensing Change Detection）可通过对比不同时相的卫星影像，自动识别地表变化， 是实现黑土地保护智能监测的关键技术手段。

本项目以基于 Transformer 的 BIT 变化检测模型为核心，构建了 BIT_CD 黑土地遥感变化检测系统， 融合深度学习变化检测、大语言模型（AI 智能分析）与 GIS 地图技术，为农业管理部门和科研机构提供 从影像上传 → 变化检测 → 结果分析 → 报告生成的全流程一站式服务。

1.2 项目目标

  • 模型层：以 BIT 双时相 Transformer 为核心，集成 7 种变化检测模型，构建统一推理框架，并基于公开数据集（SYSU-CD、LEVIR-CD、LuojiaSET-CLCD）完成训练与评估。
  • 平台层：开发前后端一体化 Web 平台，实现单张/批量检测、多模型对比、交互式调阈值、NDVI 分析、面积统计、GeoJSON 导出等完整业务闭环。
  • 智能层：接入通义千问大模型，实现检测结果 AI 解读、变化类型 AI 分类、AI Agent 浏览器自动操控。
  • 工程层：完成 Docker 容器化、生产环境部署（阿里云 ECS），通过 54 项功能与安全测试，达到可上线交付水平。

配置项取值配置项取值
数据集SYSU-CD（城市变化检测）模型结构base_transformer_pos_s4_dd8
输入尺寸256 × 256类别数2（变化 / 不变）
批次大小4损失函数交叉熵（CE）
优化器SGD学习率0.001（线性衰减至 0）
训练轮数100 epochs数据划分train 7678 / val 1921
工作进程num_workers=4训练设备GPU (cuda:0)

5.3 后端 API 与推理服务

后端基于 FastAPI + Uvicorn 提供 40+ REST API，核心设计包括：

  • 统一推理服务：集成 BIT / SNUNET / CHANGEFORMER / AFCF3D 等 7 种变化检测模型，通过统一模型接口加载权重与推理，支持多模型结果对比；
  • MD5 结果缓存：对相同输入影像对进行 MD5 指纹匹配，命中缓存时毫秒级返回历史结果，避免重复推理；
  • 交互式阈值：推理输出的分数图在前端可实时拖动阈值生成新掩膜，无需重新调用模型；
  • 多结果输出：一次推理同时产出掩膜图、分数热力图、融合叠加图与面积统计，并支持导出 GeoJSON；
  • AI 能力接入：DashScope 通义千问（qwen-turbo / vl-plus）驱动变化分析报告、6 类变化分类（水土流失/沙化/弃耕/非农化/非粮化/黑土层退化）；
  • AI Agent：browser_use + Playwright 通过 CDP 控制真实浏览器执行自然语言指令并截图返回。

6.2 典型问题排查案例

开发与测试过程中暴露并解决了一批真实问题，以下为代表性案例（均记录于测试报告 docs/TEST_REPORT.md）：

问题 1 · history 接口 500 错误（高）：GET /history 在含认证 token 请求时报 500。 排查发现路由未注入 request: Request 参数，结果图中的相对 URL 无法按当前请求地址重写，导致构造响应失败。 解决：为路由补充 Request 依赖，新增 _rewrite_url() 统一重写结果 URL（TC-FIX-05 验证通过）。
问题 2 · 结果 URL 在服务器环境失效（高）：本地开发时结果图 URL 指向 localhost，部署到云服务器后前端无法加载检测结果。 解决：历史记录与检测接口统一按当前请求 host 动态重写图片 URL（commit c63e9a6，v1.0.1）。
问题 3 · AI Agent Chrome 路径硬编码 Windows（中）：Agent 服务在 Linux 服务器上无法定位浏览器， 因代码中硬编码了 Windows 路径。 解决：改为通过 os.environ.get("LOCALAPPDATA") 动态适配跨平台 Chrome 路径（TC-FIX-04）。
问题 4 · DB 会话泄漏与模型加载兼容性：v1.1 安全审查中发现个别路由存在 SQLAlchemy 会话未及时关闭的风险， 统一调整为上下文管理器管理；同时因自定义模型架构需要，推理加载采用 weights_only=False 并记录为已知限制（BUG-04）。

9.2 主要创新点

  1. 全栈一体化自研：从底层深度学习模型到上层 Web 交互全部自主研发，覆盖"数据标注—模型训练—Web 检测—AI 解读—GIS 管理"完整链路；
  2. 多模型统一推理框架：集成 BIT、SNUNET、CHANGEFORMER 等 7 种方法，支持多模型结果并排对比，辅助交叉验证；
  3. 大模型驱动的智能解读：将通义千问与检测结果结合，自动生成结构化分析报告、六大类变化类型识别，实现"检测 + 解读"一体化；

  5. 面向黑土耕地的场景适配：自建黑土耕地数据集并集成高德地图地块管理、NDVI 分析，贴合东北黑土地保护实际业务。

9.3 应用价值与展望

系统面向东北黑土地保护中"非农化、非粮化、水土流失"等耕地变化的常态化监测需求，可显著降低人工巡查成本、提高巡查频次。 后续计划围绕以下方向持续迭代：

  • 接入 GF-2 / Sentinel-2 等卫星影像的在线拉取与自动预处理，形成"影像获取—检测—推送"的自动监测管线；
  • Agent 引入 SSE 流式推送，实时展示浏览器执行步骤（IMP-01）；
  • 检测结果批量导出 Shapefile / GeoTIFF，对接国土业务系统（IMP-03）；
  • 扩充黑土耕地标注数据集，进一步提升模型在耕地场景下的精度。
